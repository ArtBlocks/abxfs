# docs/

Operator documentation: deploying the contracts, and the record of what was audited.
**The user documentation lives in [`site/`](../site) and is published at [docs.fs.abx.io](https://docs.fs.abx.io).**

| Here | What it is |
| --- | --- |
| `deploy-runbook.md` | How to deploy ABX FS to a network: the content layer, the IPFS resolver and the org factory, the checks the scripts run, the throwaway rehearsal, and recording the result. |
| `internal-audit-summary.md` | What the internal audit found, fixed, decided and accepted, and the addresses of the frozen build. |

How to run a gateway of your own is in the user documentation:
[Run a gateway](https://docs.fs.abx.io/docs/using-abxfs/run-a-gateway).

Anything a user would read belongs in `site/content/docs/`. Planning and work tracking belong in GitHub Issues and pull
requests, not here.
